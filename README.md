# Bias-Factuality
** In a world where almost everyone is connected, it’s apparent that good news travels fast, but bad news travels even faster. Through our research we have found that even articles with generally factual information are not free from bias and emotional tones that leave the reader feeling a certain way. The project turned out better than we expected and has the potential to make a real difference for people who struggle with media literacy or people who have never challenged where they get their news from. **

*The Website takes in statements like tweets or post or even articles and spits back 3 categories:
1.Factuality
2.Bias (Emotinal and Political)
3.Emotional Tone

-Getting Started-
You can obtain a free API key through google studio by having a google account.
You can then use that API key to plug it into the Javascript file marked "// Replace with API key"
Then simply launch the website by going to the html file for this we an extension called " Live Server"
